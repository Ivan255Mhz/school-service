1. Что такое делегат

Делегат — это тип данных, который описывает сигнатуру метода (какие параметры принимает и что возвращает). Переменная делегата может хранить ссылку на метод и вызывать его.

Аналогия

Делегат — это «адресат» на конверте. Вы пишете адрес (имя метода), и письмо (вызов) доставляется нужному получателю.

Объявление делегата

// Объявляем тип делегата: принимает два int, возвращает int
public delegate int MathOperation(int a, int b);

// Метод, подходящий под эту сигнатуру
static int Add(int a, int b) => a + b;
static int Multiply(int a, int b) => a * b;

// Использование
MathOperation op = Add;           // op ссылается на Add
int result = op(3, 4);           // 7

op = Multiply;                    // теперь op ссылается на Multiply
result = op(3, 4);               // 12

Делегат как параметр метода

Самое полезное — передавать методы как аргументы другим методам.

static int Apply(int a, int b, MathOperation operation) {
    return operation(a, b);
}

int sum = Apply(5, 3, Add);       // 8
int product = Apply(5, 3, Multiply); // 15

Делегат как переменная — ключевая идея

Обычный вызовЧерез делегат
Add(3, 4) — вызов конкретного методаop(3, 4) — вызов «через переменную»
Метод известен на этапе компиляцииМетод можно подставить в runtime
Нельзя заменить на другой методМожно переключить в любой момент

2. Action, Func, Predicate

В C# уже есть готовые обобщённые делегаты — объявлять свой не нужно в 90% случаев.

ДелегатВозвращаетПараметрыКогда использовать
Action void (ничего) 0–16 параметров Когда нужно просто выполнить действие
Action<T> void 1+ параметр Action<int> — метод с одним int-параметром
Func<TResult> Возвращает TResult 0 параметров Func<int> — метод без параметров, возвращающий int
Func<T, TResult> Возвращает TResult 1+ параметр Func<int, string> — принимает int, возвращает string
Predicate<T> bool 1 параметр Для условий фильтрации: Predicate<int> 
// Action — ничего не возвращает
Action greet = () => Console.WriteLine("Привет!");
Action<string> greetName = name => Console.WriteLine($"Привет, {name}!");

// Func — возвращает значение (последний тип参数 — возвращаемый)
Func<int, int> square = x => x * x;
Func<int, int, int> add = (a, b) => a + b;

// Predicate — возвращает bool
Predicate<int> isEven = n => n % 2 == 0;

// Вызов
greet();                  // Привет!
greetName("Alex");        // Привет, Alex!
int sq = square(5);       // 25
bool even = isEven(4);    // true

Почему не свой делегат?

Объявление delegate void MyAction<T>(T item) — это лишняя строка. Action<T> делает то же самое и известен всем разработчикам.

3. Lambda-выражения

Лямбда — это анонимная функция (без имени), которая может быть передана как делегат. Синтаксис: (параметры) => тело.

Полный синтаксис vs короткий

// Полный синтаксис (явная типизация)
Func<int, int, int> add = (int a, int b) => { return a + b; };

// Типы выводятся компилятором
Func<int, int, int> add2 = (a, b) => a + b;

// Один параметр — скобки необязательны
Func<int, int> square = x => x * x;

// Нет параметров — пустые скобки
Action greet = () => Console.WriteLine("Hi!");

// Несколько строк в теле — фигурные скобки + return
Func<int, string> describe = n => {
    if (n > 0) return $"Положительное: {n}";
    if (n < 0) return $"Отрицательное: {n}";
    return "Ноль";
};

Лямбда в контексте

Лямбды раскрывают свой потенциал в методах, которые принимают делегаты:

List<int> nums = new List<int> { 1, 2, 3, 4, 5 };

// Вместо отдельного метода — сразу лямбда
var evens = nums.Where(n => n % 2 == 0).ToList();  // {2, 4}

nums.ForEach(n => Console.WriteLine(n));

// Сортировка по кастомному критерию
List<string> names = new List<string> { "Bob", "Alice", "Charlie" };
names.Sort((a, b) => a.Length.CompareTo(b.Length)); // по длине имени

4. Цепочки делегатов (multicast)

Делегат может хранить ссылку не на один метод, а на несколько. Это называется multicast delegate. Вызываются все методы по очереди.

Action onGameStart = null;
onGameStart += PlayMusic;      // добавляем метод
onGameStart += ShowIntro;
onGameStart += LoadSave;

onGameStart(); // вызовет все три метода по порядку

Операторы += и -=

ОператорЧто делает
del += MethodДобавляет метод в цепочку
del -= MethodУдаляет метод из цепочки
del?.Invoke()Безопасный вызов (если del == null, не упадёт)
Action actions = Hello;
actions += World;

actions();   // Hello\nWorld

actions -= Hello;
actions();   // World

// Безопасный вызов — если цепочка пуста, не выбросит исключение
actions = null;
actions?.Invoke();  // ничего не произойдёт

5. События (event)

Событие — это обёртка над делегатом, которая запрещает внешнему коду вызывать делегат напрямую или перезаписывать цепочку. Событие можно только подписывать (+=) и отписывать (-=).

public class Button {
    // Событие — только подписка/отписка извне
    public event Action OnClick;

    // Вызвать событие может только сам класс
    public void Click() {
        Console.WriteLine("Кнопка нажата!");
        OnClick?.Invoke();
    }
}

// Использование
Button btn = new Button();
btn.OnClick += () => Console.WriteLine("Обработчик 1");
btn.OnClick += () => Console.WriteLine("Обработчик 2");
btn.Click();  // вызовет оба обработчика

// btn.OnClick(); — ОШИБКА: нельзя вызвать событие извне
// btn.OnClick = null; — ОШИБКА: нельзя перезаписать

9. Практические задания

Задание 1: Метод с делегатом

Напишите метод Filter<T>(List<T> items, Predicate<T> condition), который возвращает новый список элементов, прошедших фильтр.

static List<T> Filter<T>(List<T> items, Predicate<T> condition) {
    List<T> result = new List<T>();
    foreach (T item in items) {
        if (condition(item))
            result.Add(item);
    }
    return result;
}

// Использование
var nums = new List<int> { 1, 2, 3, 4, 5 };
var evens = Filter(nums, n => n % 2 == 0); // {2, 4}

Задание 2: Событие таймера

Создайте класс Timer с событием OnTick. Метод Start() увеличивает счётчик и вызывает событие каждую секунду (симуляция).

public class GameTimer {
    public event Action<int> OnTick;
    private int ticks = 0;

    public void Start() {
        for (int i = 0; i < 5; i++) {
            ticks++;
            OnTick?.Invoke(ticks);
        }
    }
}

var timer = new GameTimer();
timer.OnTick += t => Console.WriteLine($"Тик: {t}");
timer.Start(); // 1, 2, 3, 4, 5

Задание 3: Action как параметр

Напишите метод Repeat(int count, Action action), который вызывает переданный action заданное количество раз.

static void Repeat(int count, Action action) {
    for (int i = 0; i < count; i++) {
        action();
    }
}

// Использование
Repeat(3, () => Console.WriteLine("Привет!"));
// Привет! Привет! Привет!
