1. Зачем нужны коллекции

Массив (int[], string[]) — самая простая коллекция, но у него есть жёсткое ограничение: размер задаётся один раз и не меняется. Если элементов станет больше, массив придётся пересоздавать вручную.

int[] scores = new int[3];
scores[0] = 10;
scores[1] = 20;
// scores[3] = 30; — ОШИБКА: IndexOutOfRangeException, места больше нет

Пространство имён System.Collections.Generic предлагает готовые структуры данных, которые сами управляют размером и оптимизированы под конкретные задачи:

КоллекцияКогда использовать
List<T>Динамический список — когда нужен упорядоченный набор элементов, который может расти
Dictionary<TKey, TValue>Пары «ключ → значение» — когда нужен быстрый поиск по ключу (например, по имени игрока)
HashSet<T>Набор уникальных элементов — когда важно, чтобы не было дублей, а порядок не важен
Queue<T> / Stack<T>Очередь (FIFO) и стек (LIFO) — для задач вроде истории действий или обработки заявок по очереди

2. List<T> — динамический список

List<T> ведёт себя как массив, но умеет расти и уменьшаться сам. Буква T в угловых скобках — это тип элементов, который вы указываете при объявлении: List<int>, List<string>, List<Tank> и так далее.

using System.Collections.Generic;

List<string> names = new List<string>();
names.Add("Alex");
names.Add("Maria");
names.Remove("Alex");       // удаляет первое совпадение по значению
names.RemoveAt(0);          // удаляет по индексу

Console.WriteLine(names.Count);   // количество элементов сейчас
Console.WriteLine(names[0]);   // доступ по индексу, как в массиве

Полезные методы List<T>

МетодЧто делает
Add(item)Добавляет элемент в конец
Remove(item)Удаляет первое совпадение по значению
RemoveAt(index)Удаляет элемент по индексу
Contains(item)Проверяет, есть ли элемент (bool)
Sort()Сортирует список на месте
CountСвойство — текущее количество элементов

4. Dictionary<TKey, TValue>

Dictionary хранит пары «ключ → значение» и позволяет находить значение по ключу почти мгновенно, без перебора всей коллекции — в отличие от поиска в List<T>.

Dictionary<string, int> hp = new Dictionary<string, int>();
hp["Warrior"] = 120;
hp["Mage"] = 70;

// безопасный поиск, не выбросит исключение, если ключа нет
if (hp.TryGetValue("Mage", out int mageHp)) {
    Console.WriteLine($"HP мага: {mageHp}");
}

foreach (var pair in hp) {
    Console.WriteLine($"{pair.Key}: {pair.Value}");
}

Важно: обращение hp["Elf"] к несуществующему ключу выбросит KeyNotFoundException, поэтому для безопасной проверки используют TryGetValue или ContainsKey.

6. HashSet<T> — только уникальные значения

HashSet<T> похож на List<T>, но автоматически отбрасывает дубликаты и не гарантирует порядок элементов. Это идеальный выбор, когда важно только «есть элемент или нет», а не его позиция.

HashSet<string> visitedRooms = new HashSet<string>();
visitedRooms.Add("Зал");
visitedRooms.Add("Кухня");
bool added = visitedRooms.Add("Зал"); // вернёт false — "Зал" уже есть, дубликат не добавится

Console.WriteLine(visitedRooms.Count); // 2, а не 3

Ещё одна сильная сторона HashSet<T> — быстрые операции над множествами: UnionWith() (объединение), IntersectWith() (пересечение), ExceptWith() (разность), как в математической теории множеств.

7. Дженерики: пишем код для любого типа

List<T> и Dictionary<TKey,TValue> — сами по себе примеры обобщённых (generic) типов. Но вы тоже можете писать свои обобщённые методы и классы — это позволяет один раз написать логику, которая будет работать с любым типом данных, сохраняя строгую типизацию.

Обобщённый метод

// T - это "заглушка" для типа, компилятор подставит реальный тип при вызове
public T GetFirst<T>(List<T> items) {
    return items[0];
}

int firstNumber = GetFirst(new List<int> { 1, 2, 3 });      // T = int
string firstName = GetFirst(new List<string> { "Alex", "Maria" }); // T = string

Обобщённый класс

Классический пример — «коробка», которая может хранить значение любого типа:

public class Box<T> {
    public T Value { get; set; }

    public Box(T value) {
        Value = value;
    }

    public void Show() {
        Console.WriteLine($"В коробке лежит: {Value}");
    }
}

Box<int> intBox = new Box<int>(42);
Box<string> strBox = new Box<string>("Привет");

Ограничения типа (where)

Иногда нужно ограничить, какие типы допустимы для T — например, потребовать, чтобы у типа был пустой конструктор, или чтобы он реализовывал определённый интерфейс. Для этого используется where.

// T обязан реализовывать IDamageable (интерфейс из прошлого урока)
public void ApplyDamage<T>(T target, int amount) where T : IDamageable {
    target.TakeDamage(amount);
}

10. Практические задания

Задание 1: List<T>

Создайте List<int> с числами 5, 12, 8, 20, 3. Найдите и выведите наибольшее число без использования LINQ (циклом).

List<int> numbers = new List<int> { 5, 12, 8, 20, 3 };
int max = numbers[0];
foreach (int n in numbers) {
    if (n > max) max = n;
}
Console.WriteLine(max); // 20
